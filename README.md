# KIMI AI Agent Dashboard v2.0.0 — Public Demo

**Static demo only. Not connected to live agents or services.**

Mobile-responsive portfolio dashboard:
- Overview, agent directory, task board, demo activity log, and safety center
- Search sample tasks
- Export sample dashboard state as JSON

## Run
Open `index.html` in a modern browser. No build step, server, API key, account, or network connection is required.

## Limitations
- All agents, tasks, statuses, progress, and logs are sample/demo data.
- No backend, authentication, telemetry, runtime integration, or persistent storage.
- Buttons only modify local demo UI or export sample JSON.
- No external network calls, AI/API requests, posting, billing, deployment, Actions, or other external actions.
- Responsive layout is provided; physical iPhone acceptance testing has not been performed.
- Not a production control panel. Do not use for operational decisions.
