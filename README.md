# KIMI AI Agent Dashboard v2.0.0 — Public Demo

**Static demo only. Not connected to live agents or services.**

Mobile-responsive portfolio dashboard: Overview, agent directory, sample task board, simulated activity log, Safety Center, task search, JSON export.

## Run
Open `index.html` in a modern browser. No build, server, API key, account, or network connection is required.

## Limitations
- All agents, tasks, statuses, progress, and logs are sample data.
- No backend, authentication, telemetry, runtime integration, or persistent storage.
- Buttons only modify local demo UI or export sample JSON.
- No network/API calls, posting, billing, deployment, Actions, or external actions.
- Responsive layout included; physical iPhone acceptance test not performed.
- Not a production control panel.
